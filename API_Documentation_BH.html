Descripción del Proyecto

BH – API es una extensión de Microsoft Dynamics 365 Business Central (AL) que expone datos de negocio como servicios OData v4 REST para su consumo por sistemas externos, herramientas de análisis o automatizaciones de procesos. Todas las páginas siguen el estándar de API nativa de BC con soporte completo para operaciones CRUD.

El proyecto incluye soporte para localización colombiana (D365LATAM), exponiendo campos tributarios de la DIAN como tipo de persona, tipo de documento NIT y responsabilidades fiscales.

Autenticación y URL Base

Todas las APIs usan autenticación OAuth 2.0 (Azure AD) o Basic Auth según la configuración del tenant. La URL base sigue el patrón estándar de Business Central Online:

// URL Base https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}/api/bh/bh/beta/ // Ejemplo con el sandbox configurado https://api.businesscentral.dynamics.com/v2.0/ 10657a47-53a7-4493-b90b-033cc0505242/sandbox1012/api/bh/bh/beta/

Patrones Comunes

Clave primaria OData
SystemId (GUID)
Inserción diferida
DelayedInsert = true
ℹ️

El campo id (SystemId) es generado automáticamente por BC y es inmutable. Úsalo como identificador único en integraciones. Todos los endpoints aceptan el parámetro $filter, $select, $expand, $top y $skip de OData v4.

Operaciones Soportadas (CRUD)

Método HTTP Operación Ejemplo
GET Leer todos los registros GET /customers

APIs del Ciclo de Ventas
